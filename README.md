Travel Agency Website

A web-based Travel Agency Management project built using Python, Flask, HTML, CSS, and MySQL.

Technologies Used
- Python
- Flask
- HTML
- CSS
- MySQL

Project Structure
- `app1.py` – Flask application
- `templates/` – HTML pages
- `static/` – CSS styling
- `requirements.txt` – Python dependencies

Features
- User registration
- User login
- Travel destination display
- Booking functionality

Setup
1. Install Python.
2. Install the required packages using:

   `pip install -r requirements.txt`

3. Configure your MySQL database connection.
4. Run the application:

   `python app1.py`

5. Open the local address displayed in your terminal in a browser.

*Note: MySQL database configuration and setup are required before running the application.*
